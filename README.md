# PALLAS web app v0.0.1 &#127963;

## About

PALLAS is a multimodal classifier of molecular subtypes in pediatric acute leukemias.

## Install

Run `pip install -r requirements.txt`

## Configure MLflow

To enable inference using models in your MLFlow instance, copy `conf/mlflow.env.example` to `conf/mlflow.env` and edit it with your own values.

## Run

`streamlit run app.py`
